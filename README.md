# Kinweb

A global, crowdsourced family-heritage platform. Claim your profile, connect your relatives, and watch your family tree grow organically — like a spider web, one true connection at a time.

Full project brief: [`docs/PROJECT_BRIEF.md`](docs/PROJECT_BRIEF.md) — read it before writing product code. The privacy and consent design in there is not optional scope; it's the load-bearing part of this product.

## Status

Pre-scaffold. No app code yet. This repo currently holds the spec that scaffolding work builds against.
